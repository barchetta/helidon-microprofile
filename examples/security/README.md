# Security

- [Multiple applications](multiple-applications/README.md): role-based access across several JAX-RS applications, using locally configured users.
- [OIDC](oidc/README.md): OpenID Connect authentication with an external identity provider. Requires provider and client configuration.
- [IDCS](idcs/README.md): Oracle Identity Cloud Service integration. Requires a configured identity tenant.

Run `mvn package` in this directory to build all three examples. See each example for runtime configuration and usage.
